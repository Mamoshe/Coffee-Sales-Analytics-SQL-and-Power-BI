# cofee-sales-analytics
# Project Overview
This project analyzes coffee sales data using SQLite Power BI. The goal is to explore sales performance, revenue, product popularity, and payment methods.

# Tools Used
SQL,Power BI

# Business Questions

How many sales transactions are recorded?

What is the total revenue?

Which coffee types are the most popular?

Which coffee types generate the most revenue?

Which payment methods are used most frequently?

How do sales and revenue change over time?

# Methodology

Imported the source CSV files into SQL.

Explored the dataset using SQL queries.

Calculated sales counts and revenue.

Analyzed sales performance by coffee type and payment method.

Created visualizations and dashboards in Power BI.
