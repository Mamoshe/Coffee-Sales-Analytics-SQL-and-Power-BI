# Coffee Sales Analytics: SQL + Power BI
# Project Overview
This project analyzes coffee sales data using SQLite and Power BI. The goal is to explore sales performance, revenue, product popularity, and payment methods.

# Tools Used
SQLite ,Power BI

# Business Questions

How many sales transactions are recorded?

What is the total revenue?

Which coffee types are the most popular?

Which coffee types generate the most revenue?

Which payment methods are used most frequently?

How do sales and revenue change over time?

# Methodology

Imported the source CSV files into SQL.

Explored the dataset using SQL queries.

Calculated sales counts and revenue.

Analyzed sales performance by coffee type and payment method.

Created visualizations and dashboards in Power BI.

# Key Findings

1) The most popular coffee type is Latte (23% of total Sales).
2) Card sales exceeded cash sales. (by 73%)
3) The biggest number of sales was in March and October.
4) Peak Hours of Sales are 10:00–11:00 AM and 7:00–8:00 PM.
